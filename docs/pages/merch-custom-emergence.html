Wordmark

Original artwork reproduces the uploaded PNG exactly — it has no letterforms, so the name is ignored until you change something. Source field rebuilds that density around your name.

Showing the original artwork, so the name is not being drawn. Type here or touch any setting below to start generating from it.

One line per row of the mark, up to four. The tile alphabet is five rows tall, so everything sets in caps. The selfdriven mark always leads the first row.

Alignment

Alignment sets how shorter lines sit against the longest one, so it needs a second line to do anything.

Dissolve knocks tiles out of the letters. The field fills the gaps around them, which is how the letters emerge from the band rather than sit on it.
